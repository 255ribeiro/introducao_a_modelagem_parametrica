
# Instalando Plugins baixados

1. Abra a pasta de pluguins do Grasshopper. como mostrado em [special folders](../../gh_interface/gh_special_folders.md)

1. Caso o Rhino e o Grasshopper estejam abertos, feche os programas.

1. Baixe o pluguin a ser instalado. exemplo [Sunglasses](https://github.com/DanielAbalde/Sunglasses)

1. Clique com o botão direito no(s) arquivo(s) baixado(s), escolha a opção propriedades e  clique em desbloquear.

1. Copie o(s) arquivos desbloqueados para a pasta de pluguins do Rhino 3D.

1. Reinicie o Rhino e o Grasshopper.
