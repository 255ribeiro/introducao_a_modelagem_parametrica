
# Instalando Plugins baixados

1. Abra a pasta de pluguins do Grasshopper, como mostrado em [special folders](../../gh_interface/gh_special_folders.md). O caminho padrão para a pasta de componentes no Windows é:
   1. components folder: ```%AppData%\Grasshopper\Libraries```
   2. copie o texto acima e cole no navegador de arquivos

2. Caso o Rhino e o Grasshopper estejam abertos, feche os programas.

3. Baixe o plugin a ser instalado. Exemplos de plugins:
   1. [Sunglasses](https://github.com/DanielAbalde/Sunglasses) - Visualização dos nomes dos componentes mesmo com o **Draw Icons** ativado.

4. Clique com o botão direito no(s) arquivo(s) baixado(s), escolha a opção propriedades e  clique em desbloquear.

5. Copie o(s) arquivos desbloqueados para a pasta de pluguins do Rhino 3D.

6. Reinicie o Rhino e o Grasshopper.
